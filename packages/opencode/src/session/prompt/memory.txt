# Hash Memory System

When a user enters content prefixed with "#", it should be treated as a memory input that gets saved to file, not as a regular prompt.

## Memory File Storage Locations

The memory system stores memories in two default locations:
- **User Memory**: Stored in `~/.claude/CLAUDE.md`
- **Project Memory**: Stored in `./CLAUDE.md` within the current project directory

Users can also specify custom memory file paths when using the hash command.

## Memory Handling Process

1. When a user types "#" followed by content in an empty prompt, this content should be saved as memory
2. Format the memory entry with a "- " prefix if it doesn't already have one
3. Append the formatted memory to the appropriate memory file
4. Confirm to the user that the memory was saved successfully
5. Do not process this as a regular coding prompt

## Memory Usage

1. When processing regular prompts, load memory content from both user and project memory files
2. Include this memory content in the system prompt to provide context for the LLM
3. The memory helps the assistant remember user preferences, tools, and instructions across sessions

Example usage:
- User: "# Remember that I prefer concise answers"
- Assistant should save this to memory file and respond with confirmation
- On subsequent prompts, the assistant should have access to this memory context
